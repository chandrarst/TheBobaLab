I developed a simple website called TheBobaLab as part of my elective course project in Digital Marketing. The website was built entirely with HTML, CSS, and JavaScript, where I experimented with delivering a premium and interactive user experience, such as a three-step ordering process, customization of sweetness/ice/toppings, and a showcase of signature drinks.

Even though I only used basic technologies (without any frameworks or backend), I focused on maximizing the design and functionality to keep it both appealing and responsive across devices. The website was deployed using GitHub Pages for free, making it accessible online.

This project gave me the opportunity to practice my fundamental front-end skills, explore UI/UX concepts, and prove that even with simple technologies, it is possible to create a solid and engaging result.
